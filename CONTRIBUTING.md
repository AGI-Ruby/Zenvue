# Contributing to Zenvue

Zenvue is maintained at https://github.com/alienzhang23/Zenvue. File Zenvue bugs and feature requests in this repository, including platform, reproduction steps and relevant logs with private information removed.

1. Clone your fork and create a feature branch.
2. Prepare the platform toolchains described in README.md and RELEASING.md, then run npm ci.
3. Make focused changes. Preserve upstream copyright, license and attribution notices.
4. Run the relevant tests, npm run typecheck and the appropriate build. Include validation details with your pull request.

Contributions are licensed under AGPL-3.0-only. Do not submit secrets, personal recordings, proprietary SDKs or code/assets without compatible rights. Local planning and generated artifacts are excluded by .gitignore.

The original upstream contribution guide is preserved in docs/upstream/CONTRIBUTING.md for historical reference.
